# Flikart-review-sentiment-analysis
🚀 A Machine Learning + NLP project to classify Flipkart product reviews as Positive or Negative.

📖 Overview

This project uses Natural Language Processing and Machine Learning techniques to analyze customer reviews and predict sentiment.

🎯 Features

Text preprocessing & cleaning

TF-IDF feature extraction

ML model training & evaluation

Sentiment prediction on new reviews

Deployment-ready workflow

🛠️ Tech Stack

Python

Pandas, NumPy

Scikit-learn

NLP (NLTK)

TF-IDF Vectorizer
